Capabilities

Everything your agents need.
Nothing they don't.

Seknova is the MCP manager for browser sessions — real browsers, real sessions, real control.

MCP

Native MCP Server

A Streamable HTTP endpoint at 127.0.0.1:7777/mcp exposes every browser-drive tool — navigate, click, type, screenshot, cookies, tabs — to any MCP client.

Claude / Cursor
:7777/mcp
Browser
Multi-session

Parallel Browser Sessions

Run dozens of isolated Chromium and Firefox profiles at the same time. Each gets its own cookies, storage, proxy, fingerprint, and timezone — zero bleed between them.

Anti-detect Engine

Canvas, WebGL, audio, fonts, and WebRTC fingerprints spoofed at the C++ level in a patched Chromium. No JS injection — the patch lives in V8 and Blink themselves.

Sync

Encrypted Cloud Sync

Profiles and MCP project configs sync across your Macs via S3, R2, or any S3-compatible store. No backend server. Coordination is pure atomic conditional writes — Kopia encrypts the data.

Persistent Sessions

Cookies, IndexedDB, localStorage all persist on disk per profile. Your AI agent logs in once and stays logged in — across restarts, across AI sessions.

Open Source

Self-hosted & MIT

No account, no license server, no telemetry. Profiles live in plain SQLite on your disk. Fork it on GitHub — it's fully MIT licensed.

Setup

From install to agent-ready
in three steps.

01

Create a profile

Name your profile, choose an engine (CloakBrowser or Camoufox), set a proxy and fingerprint persona. The profile directory is provisioned immediately.

02

Connect your agent

Copy the bearer token from MCP → Connect. Add Seknova to your Cursor, Claude Desktop, Codex, or Kiro config — or let Projects write the config file automatically.

03

Let your agent work

Your agent calls launch_profile, then navigates, clicks, types, and reads pages. Login state persists across every session.
